## Examples

Exploring a live, working project is one of the clearest ways to understand how the standard operates in practice.

### Built with love and FISS

- **[`fiss-lint` Intellectual Space](https://github.com/AndreyVorozhko/fiss-lint/tree/main/FISS)** — a reference real-world implementation of the `FISS/` directory structure in the official linter repository.

  It demonstrates:
  - root entry point organization (`INDEX.md`) with strict `Read when:` read conditions;
  - concise baseline context (`BOOTSTRAP.md`);
  - knowledge area structuring (`knowledge/subject/` and `knowledge/project/`);
  - project-level overrides for external mechanisms and agent skills (`overrides/`);
  - handoff state tracking and task continuity records (`state/fiss-handoff.md`).
