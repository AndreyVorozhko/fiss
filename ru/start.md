## Быстрый старт

Минимальная структура состоит из двух обязательных файлов:

```text
FISS/
├── INDEX.md
└── BOOTSTRAP.md
```

- **`FISS/INDEX.md` — точка входа.** Содержит ссылки и условия чтения материалов.
- **`FISS/BOOTSTRAP.md` — базовый контекст.** Помогает первоначально сориентироваться в проекте.

Минимальный `FISS/INDEX.md`:

```markdown
# Интеллектуальное пространство проекта

- [Базовый контекст](BOOTSTRAP.md)
  Read when: начинается работа с проектом или требуется первичная ориентация.
```

В `FISS/BOOTSTRAP.md` следует кратко объяснить назначение проекта, ключевые правила и ограничения, важные определения и особенности, без которых проект легко понять неправильно.

Этот файл должен оставаться небольшим. Сведения, нужные только для отдельной области работы, следует выносить в соответствующую область. Такой подход реализует [принцип «Начинайте с малого»](./intellectual-space.md#principle-compact): в маленьком проекте всё содержательное наполнение может помещаться в `FISS/BOOTSTRAP.md`; `FISS/INDEX.md` при этом остаётся обязательным. Искусственно делить короткий текст не требуется — сведения и структуры добавляются тогда, когда для них появляется реальное содержание или потребность в контексте.

Для команды рекомендуется добавить ссылку на `FISS/INDEX.md` в основной README проекта или другое привычное место начала работы. Если проект использует `AGENTS.md` или иной корневой файл инструкций для ИИ, этот файл должен направлять агента в `FISS/INDEX.md` и не должен дублировать содержание пространства.
