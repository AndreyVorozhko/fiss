## Экосистема инструментов FISS

Для поддержки стандарта, автоматической проверки соответствия и удобной интеграции в рабочие процессы создана экосистема вспомогательных инструментов.

### Линтер FISS (`fiss-lint`)

**[`fiss-lint`](https://github.com/AndreyVorozhko/fiss-lint)** — официальный инструмент статического анализа и валидации интеллектуального пространства проекта.

Ключевые возможности:
- **Проверка структуры:** наличие обязательных файлов `FISS/INDEX.md` и `FISS/BOOTSTRAP.md`, корректность разделов (`knowledge/`, `human/`, `state/`).
- **Валидация навигации:** соблюдение строгого двухстрочного формата записей в индексах и обязательного нелокализуемого маркера `Read when:`.
- **Целостность ссылок:** проверка существования целевых файлов для всех ссылок в индексах и проверка маркеров производного знания `Derived from:`.
- **Интеграция в CI/CD:** быстрый запуск в консоли разработчика или автоматических конвейерах проверки pull request и коммитов.

Репозиторий проекта: [github.com/AndreyVorozhko/fiss-lint](https://github.com/AndreyVorozhko/fiss-lint)

### Навыки для ИИ-агентов (`fiss-skills`)

**[`fiss-skills`](https://github.com/AndreyVorozhko/fiss-skills)** — набор специализированных навыков (agent skills) для ИИ-ассистентов, автоматизирующих работу с интеллектуальным пространством.

В состав входят:
- **`fiss-init`:** инициализирует новое интеллектуальное пространство FISS с нуля. Создаёт корневые файлы, анализирует проект для обнаружения классов работы (FISS-релевантная vs операционная), формирует таксономию классификации работы, настраивает точки входа и механизмы передачи. Используется, когда в репозитории ещё нет соответствующего стандарту интеллектуального пространства.
- **`fiss-maintain`:** отвечает за непрерывность интеллектуального пространства при завершении задач. Различает FISS-релевантную и операционную работу, управляет фиксацией состояния передачи (handoff: `pending` → `synchronized`) для работы, производящей FISS-релевантные результаты, поддерживает таксономию классификации работы, обновляет навигацию и ссылки, определяет размещение операционных артефактов и сохраняет полезный контекст.
- **`fiss-validate`:** выполняет детальную проверку интеллектуального пространства на соответствие инвариантам стандарта без изменения файлов. Проверяет таксономию классификации работы, контролирует, что требования к трёхфазовому переходу применяются только для FISS-релевантной работы, а операционная работа корректно обходит переходы состояния, дополняя механический анализ линтера проверкой семантической связности.

Репозиторий проекта: [github.com/AndreyVorozhko/fiss-skills](https://github.com/AndreyVorozhko/fiss-skills)
